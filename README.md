# 🎁 digiganj — ابزار پژوهشی «شکار گنج» دیجی‌کالا

**یافتن سریع‌تر نشانهٔ رمز، با کمترین درخواست ممکن — و ثبت شواهدی که قابل استناد باشد.**

## قالب ایونت در دوره‌های مختلف (مهم)

قالب ایونت بین سال‌ها عوض شده و ابزار هر دو را می‌شناسد:

| دوره | قالب کد | کجا پنهان است | فهرست محصولات |
|---|---|---|---|
| **۱۴۰۰** | ۱۰ کاراکتر مخلوط حرف و رقم — مثل `fvKA4jd9DP` | گالری کالاهای فهرست `/ajax/treasure-hunt/products/` | فهرست ایونت |
| **۱۴۰۳** | همان ۱۴۰۰ | همان | همان |
| **۱۴۰۵ (جاکدی)** | **`DK` + ۳ یا ۴ حرف** — مثل `DKQWF` یا `DKAXBG`؛ ۵ یا ۶ کاراکتر، **فقط حروف** | گالری کالاهای **دسته‌بندی‌های اعلام‌شده** | جستجوی دسته‌بندی، هر ساعت عوض می‌شود |

در ۱۴۰۵ دسته‌بندی‌ها و جایزه‌های هر دور **هر ساعت** در صفحهٔ
`/landings/prize-catcher/?tab=hunt` اعلام می‌شوند. شناسهٔ دسته‌بندی‌ها را
از لینک «دیدن کالاها»ی همان صفحه بردارید و در چالش بنویسید:

```bash
digiganj challenge add --id bf-1405-round2 --title "دور دوم" \
  --start "2026-11-26T22:00:00+03:30" --end "2026-11-26T23:00:00+03:30" \
  --category 10942 --category 5604 --list-path "/search/?categories%5B0%5D=10942&categories%5B1%5D=5604&sort=7"
```

## این پروژه چه می‌کند؟

در ایونت «شکار گنج» دیجی‌کالا (بلک‌فرایدی)، یک کد در تصویرِ گالری یکی از
محصولات مخفی می‌شود و اولین کسی که کد را در فرم وارد کند برنده است.
در ۱۴۰۰ چند نفر با تحلیلِ **نام فایل تصویر روی CDN** کشف کردند که فایل رمز،
timestamp لحظهٔ انتشار را در نامش دارد؛ یعنی می‌توان بدون نگاه کردن به تصویر
فهمید کدام تازه است.

`digiganj` همان ایده را به یک ابزار منظم و کامل تبدیل می‌کند:

| قابلیت | توضیح |
|---|---|
| **تشخیص زمان از نام فایل** | یونیکس ثانیه/میلی‌ثانیه، `YYYYMMDDhhmmss`، تاریخ با خط‌تیره؛ چند الگو |
| **دو قالب رمز** | کد قدیمی ۱۰ کاراکتری و کد جدید `DK…` — واریانت‌ها هم از قالب بیرون نمی‌زنند |
| **دسته‌بندی‌های هر دور** | آدرس جستجوی دسته‌بندی به‌جای فهرست ثابت؛ هر ساعت قابل به‌روزرسانی |
| **بدون دانلود در مرحلهٔ اول** | گالری‌ها فقط با JSON گرفته می‌شوند؛ تصویر فقط برای نامزدهای برتر دانلود می‌شود |
| **حالت آماده‌باش** | پیش از شروع چالش، ایندکس کامل ساخته می‌شود؛ در لحظهٔ شروع فقط «تفاوت» دیده می‌شود |
| **OCR دو موتوره** | tesseract (اگر نصب باشد) + موتور داخلی بدون وابستگی (شبکهٔ ۲۰×۲۴ + جستجوی پرتوی) |
| **کادر رمز برای چشم شما** | برش خودکار کادر رمز و بزرگ‌نمایی ۳ برابر — وقتی OCR مردد است، خودتان در یک ثانیه می‌خوانید |
| **خانوادهٔ رمز** | همهٔ خوانش‌های یک کد کنار هم با شمارش؛ ابتدا پرتکرارترین، بعد گونه‌های بعدی |
| **داشبورد زنده** | صفحهٔ وب خودبسنده با KPI، گاه‌شمار و هشدارها؛ حالت زنده با به‌روزرسانی خودکار |
| **هشدار فارسی** | کنسول + تلگرام + وبهوک + اعلان میزکار |
| **گزارش شواهد** | HTML راست‌به‌چپ: نامزدها، گاه‌شمار انتشار، جدول هشدارها، محدودیت‌ها |
| **همه‌چیز به فارسی** | لاگ‌ها، پیام‌ها، تاریخ جلالی، اعداد فارسی |
| **محترم و پایدار** | فاصلهٔ تطبیقی، backoff نمایی، مدار حفاظتی؛ در فشار **کندتر** می‌شود |

## استفادهٔ واقعی (با دیجی‌کالا)

> ⚠️ پیش از اجرا، بخش «اخلاق و مسئولیت» را بخوانید.

```bash
# ۱) بررسی سلامت محیط و دسترسی
digiganj doctor

# ۲) ساخت پیکربندی و تنظیم زمان چالش واقعی
digiganj config init
digiganj challenge list

# ۳) خواندن فهرست محصولات (فقط مشاهده)
digiganj list --show 40

# ۴) اسکن یک‌باره
digiganj scan --once

# ۵) حالت بلندمدت با آماده‌باش ۱۰ دقیقه پیش از شروع
digiganj scan --watch --prewarm 10 --interval 30

# ۶) نتایج
digiganj candidates --top 20     # نامزدهای نشانه‌دار
digiganj codes                   # رمزهای استخراج‌شده (خانواده‌بندی‌شده)
digiganj card                    # فهرست کادرهای رمز
digiganj card 31 --out card.png  # برش کادر یک تصویر برای خواندن با چشم
digiganj dashboard               # داشبورد HTML (عکس فوری)
digiganj dashboard --serve       # داشبورد زنده روی http://127.0.0.1:8811
digiganj report --embed          # گزارش HTML با تصاویر جاسازی‌شده
digiganj evidence                # بستهٔ شواهد (HTML + JSON خام)
```

## چطور «سریع» است؟

«سریع‌ترین» یعنی کم‌درخواست‌ترین، نه پرتهاجم‌ترین:

1. **ایندکس یک‌بار، استفادهٔ چندباره**: یک بار کل گالری‌ها خوانده می‌شوند
   (`/v1/product/dkp-{id}/`)، از آن به بعد فقط محصولاتی که در دورهٔ قبل
   گالری‌شان عوض شده — چه بسا هیچ‌کدام — دوباره خوانده می‌شوند.
2. **تشخیص تغییر بدون دانلود**: `stamp_ts` از نام فایل کافی است. تصویر فقط
   برای ۵۰ نامزد برتر دانلود می‌شود.
3. **آماده‌باش**: ایندکس کامل پیش از شروع؛ در لحظهٔ شروع فقط یک چرخه.
4. **کش شرطی**: ETag/Last-Modified → ۳۰۴ یعنی همان محتوای قبلی.
5. **اجتناب از محدودیت نرخ**: فاصلهٔ تطبیقی از ۰.۰۶s شروع می‌شود؛ در ۴۲۹/۵۰۳
   دو برابر می‌شود؛ پس از ۸ موفقیت پیاپیِ پیوسته کم می‌کند. یعنی ابزار در
   فشار **کندتر** می‌شود — دقیقاً برعکس رفتار پرتهاجم.
6. **چرخش هویت فقط پس از شکست**: UA و پروفایل در طول نشست **ثابت** می‌مانند
   (چون تغییر مداوم خودش نشانهٔ ربات است). هویات فقط پس از سه بلوکهٔ پیاپی
   عوض می‌شود.

## چالش با تنظیمات

```jsonc
{
  "challenges": [{
    "id": "bf-1403",
    "title": "شکار گنج بلک‌فرایدی ۱۴۰۳",
    "starts_at": "2024-11-20T00:00:00+03:30",
    "ends_at":   "2024-11-30T23:59:59+03:30",
    "list_path": "/treasure-hunt/products/",
    "era": "۱۴۰۳",
    "enabled": true
  }],
  "epoch_window_before": 600,
  "epoch_window_after": 1800,
  "concurrency": 8,
  "ocr_enabled": true,
  "telegram_bot_token": "…",
  "telegram_chat_id": "…"
}
```

مهم‌ترین کلیدها:

| کلید | معنا |
|---|---|
| `epoch_window_after` | چند ثانیه پس از شروع، تصویر «تازه» حساب شود (پیش‌فرض ۱۸۰۰) |
| `alert_score` | آستانهٔ هشدار (پیش‌فرض ۵۵) |
| `probe_mode` | `auto\|head\|get` — کم‌هزینه‌ترین راه تشخیص تغییر |
| `gallery_source` | `auto\|api\|html` — مسیر گرفتن گالری |
| `transport` | `auto\|httpx\|curl_cffi` |
| `proxies` | فهرست پروکسی برای توزیع بار (با احترام به محدودیت) |

## اخلاق و مسئولیت

این ابزار برای **پژوهش، شفافیت و شکار عادلانه** ساخته شده است، نه برای
سوءاستفاده.

**چه می‌کند:**
- فهرست و گالری محصولات را با همان API عمومی‌ای می‌خواند که مرورگر شما
  هنگام دیدن صفحه استفاده می‌کند.
- سرعتش را با فاصلهٔ تطبیقی کنترل می‌کند و در فشار، کندتر می‌شود.
- اگر خودتان بگویید، با کوکی خودتان کار می‌کند (برای دیدن همان چیزی که
  شما می‌بینید).

**چه نمی‌کند:**
- ❌ کد تخفیف را به‌طور خودکار روی هیچ حسابی ثبت نمی‌کند.
- ❌ فرم خرید را پر نمی‌کند، سفارش نمی‌دهد، پارتیشن نمی‌سازد.
- ❌ رمز را حدس نمی‌زند؛ فقط نشانهٔ تصویر را پیدا می‌کند و اگر OCR رمزی
  خواند، آن را **به شما** نشان می‌دهد.
- ❌ به حساب دیگران حمله نمی‌کند؛ کوکی/توکن شما فقط برای درخواست‌های
  خودتان استفاده می‌شود.

**شما مسئولید:**
- قوانین دیجی‌کالا و شرایط ایونت را بخوانید.
- اگر سرویس‌دهنده محدودیتی اعمال کرد، ابزار **کندتر** می‌شود؛ آن را از
  راه‌های پرتهاجم (پروکسی‌های انبوه، حساب‌های متعدد) دور نزنید — این
  کار هم از نظر اخلاقی اشتباه است و هم شانس بن‌شدن را بالا می‌برد.
- هیچ‌کدام از نتایج، «اثبات تقلب» نیست؛ فقط شاهد است. برای ادعای عمومی،
  داده‌خام را همراه گزارش منتشر کنید.

## دربارهٔ «فیک بودن» ایونت

بخشی از انگیزهٔ این ابزار، پژوهش دربارهٔ شفافیت ایونت است. آنچه **می‌توان**
به‌عنوان شاهد ثبت کرد:

1. زمان نام فایل تصویر (روی CDN) نسبت به شروع رسمی چالش.
2. اینکه آیا تصویرِ رمز پیش از شروع چالش هم روی سرور بوده است یا نه.
3. آنچه OCR از تصویر می‌خواند (و اینکه آیا کد با فرم رسمی پذیرفته می‌شود —
   این را فقط خودتان در بازهٔ مجاز آزمایش کنید).

آنچه **نمی‌توان** نتیجه گرفت:

- «من پیدا نکردم» ≠ «رمز وجود ندارد». ممکن است کندی شبکه، تأخیر سرور، یا
  محدودسازی موقت مانع شده باشد.
- «کد من پذیرفته نشد» ≠ «تقلب». ممکن است کد پیش از شما استفاده شده باشد
  (در ایونت ۱۴۰۰ همین اتفاق برای برندگان رخ داد و دیجی‌کالا گفت خطای متن
  پیام بوده است).

`digiganj evidence` بستهٔ شواهد (HTML + JSON خام + زمان‌ها) می‌سازد تا هر
ادعایی قابل بازبینی باشد.
